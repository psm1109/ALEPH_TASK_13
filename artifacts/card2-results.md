# 카드 2 — 첫 판과 직접 사용 결과

## 첫 화면

- 논문: 성격 특성과 청취 음악의 음향·가사 특성의 관계 — 박선민(2026)
- 안내: 이 앱은 함께 들을 음악을 정하기 어려운 친구들이 곡 신청과 투표로 다음 곡을 고르도록 돕습니다.
- 카드 1 원문을 첫 화면에 그대로 표시했습니다.
- 논문의 330명, r=0.066, 95% 신뢰구간 −0.045~0.181을 표시했습니다.
- 화면 이미지: `card2-first-screen.png`

## 논문 결과의 적용 범위

이번 표본에서 외향성과 평균 음향적 긍정성의 뚜렷한 양의 관계를 확인하지 못했다는 결과에 착안했습니다. 성격 점수로 곡을 추정하는 대신, 사용자가 직접 신청하고 투표하도록 구현했습니다. 실제 대기열에는 찬성 +1, 패스 −1의 합계가 반영됩니다. 동점이면 먼저 신청한 곡이 우선합니다.

이 점수와 동점 규칙은 앱의 운영 규칙이며 논문에서 도출한 공식은 아닙니다. 논문의 상관계수를 추천 가중치로 사용하지 않습니다. 논문은 투표 방식이나 앱의 효과를 검증하지 않았습니다. BRB-C04를 논문의 수치를 계산에 직접 사용하는 것으로 해석한다면 충족한 것으로 볼 수 없으며, 현재 구현은 연구 결과를 설계 원칙으로 적용한 것입니다.

## 직접 해 본 세 가지 행동

2026년 10월 16일 로컬 앱 브라우저에서 확인했습니다.

| 행동 | 확인 결과 |
|---|---|
| 방 만들기 | 방 이름과 닉네임 입력 후 6자리 방 코드 발급, 참여자 1명 표시 |
| 곡 신청 | 정상 YouTube 링크로 현재 곡 등록, 추가 곡은 대기열 1곡으로 표시. 공식 플레이어의 재생 상태도 확인 |
| 투표 | 대기곡 찬성 시 1표와 선택 상태 표시. 패스로 교체 시 패스 1표와 선택 상태 표시 |

## 잘못된 입력

| 입력 | 확인 결과 |
|---|---|
| 방 코드 `abc` | 형식 안내 표시, 첫 화면 유지 |
| `https://example.com/not-youtube` | 올바른 유튜브 링크 입력 안내, 방 유지 |
| 영상 ID가 한 글자 부족한 YouTube 링크 | 오류 안내, 올바른 링크로 고친 뒤 정상 신청 |
| 재생할 수 없는 영상 | 재생 불가 안내 후 다음 신청 가능 |

제목 검색 키가 없는 환경에서는 링크 신청 탭을 먼저 표시하도록 했습니다. 대기열에는 첫 곡 이후 한 곡을 더 신청해야 투표할 수 있다는 안내를 추가했습니다.

## 검증과 한계

- 기존 자동 검사 10개 통과.
- 빌드 통과.
- 브라우저에서 세 가지 행동과 오류 후 재입력을 확인.
- 실제 처음 방문한 사용자 대상의 1분 사용성 측정은 수행하지 않음.
- 제목 검색은 API 키가 없는 로컬 환경이므로 링크 신청 경로를 확인함.
- 테스트 방은 확인 후 퇴장하여 정리함.
- 이번 변경은 `public/app.js`, `public/style.css`와 이 결과 기록·이미지에 한정함. 기존 작업 중이던 다른 파일 변경은 보존함.

## 첫 화면 간소화 반영

사용자의 후속 요청에 따라 첫 화면의 바탕이 된 논문 영역(제목·카드 1 원문·결과 수치)을 제거했습니다. 앱 소개 한 문장과 세 단계 이용 안내는 유지했습니다. 논문 제목과 연구 결과는 하단의 이 앱이 시작된 연구 링크에서 확인할 수 있습니다. 이에 따라 BRB-C03의 논문 제목 첫 화면 표시는 현재 적용하지 않습니다. 기존 첫 화면 이미지는 변경 전 기록입니다.
